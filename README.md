# Insurance Underwriting & Claims Analysis Using SQL

## Project Overview
This project analyses sample insurance data using SQL to understand policy distribution, customer claims, risk categories, underwriting decisions and claim processing time.

## Project Objectives
- Analyse insurance policy distribution.
- Understand customer claim patterns.
- Examine different risk categories.
- Analyse underwriting decisions.
- Calculate average claim processing time.

## Tools Used
- MySQL Workbench
- SQL
- GitHub

## Dataset Details
- Source: Kaggle.com
- Total Records: 20
- Data Type: Dummy/Sample Insurance Data

The dataset includes applicant details, policy information, claim details, risk categories and underwriting decisions.

## Business Questions
This project answers 12 business questions related to:
1. Claims by gender
2. Claims by country
3. Claims by city
4. Most frequently purchased policy type
5. Policy status distribution
6. Claim status percentage
7. Risk category distribution
8. Claims submitted by each customer
9. Underwriting decision distribution
10. Average claim processing time
11. Policies under each policy type
12. Customers with more than one previous claim

## Key Findings
- Health insurance is the most common policy type.
- 65% of applications fall under the low-risk category.
- 80% of applications have an approved underwriting decision.
- 55% of claims have an approved status.
- Average claim processing time is approximately 11.65 days (subject to final data verification).

## Skills Demonstrated
SQL querying, data analysis, filtering, grouping, aggregate functions, subqueries and date calculations.

## Conclusion
This project helped me develop practical SQL skills and understand how insurance data can be analysed to generate meaningful business insights.
